# Foodies

Internal operations and compliance platform. Start with [AGENTS.md](AGENTS.md) for conventions, [docs/spec.md](docs/spec.md) for the product and [docs/status.md](docs/status.md) for where the build stands.

| Path | What it is |
|---|---|
| `api/` | Go REST API. `openapi.yaml` is the contract. |
| `api/cmd/server` | API entry point. |
| `api/internal/http` | Thin handlers, error mapping, middleware. `apigen/` is generated. |
| `api/internal/service` | Business logic. |
| `api/internal/db` | Generated by sqlc. Queries live in `api/db/queries`. |
| `api/db/migrations` | goose SQL migrations. |
| `api/codegen` | oapi-codegen config, overlay and template. |
| `api/codegen/scaffold` | Writes the CRUD layer of a slice (`crud_*` files) from the data model and spec. Run by hand. Needs Python and PyYAML. |
| `api/internal/integration` | End-to-end API tests against Postgres in testcontainers. |
| `api/tools` | Pinned generators and linters, in their own Go module. |
| `web/` | Next.js App Router frontend. `lib/api/schema.d.ts` is generated. |

## Setup

Needs Go, Node 22, pnpm and Docker. Versions are pinned in `api/go.mod`, `.nvmrc` and `web/package.json`.

```bash
cp .env.example .env
make db-up
make migrate-up
make seed-demo
make run-api
make run-web
```

All configuration lives in `.env` at the repository root. The Makefile exports it to the API, Compose reads it for Postgres, and `web/next.config.ts` loads it for Next.js. Do not add `web/.env*` files.

`make seed-demo` loads a made-up organisation. Every demo user signs in with their employee number (`E1001` to `E1022`) and the `SEED_PASSWORD` from `.env`. Finance and admin roles enrol two-factor at first sign-in.
